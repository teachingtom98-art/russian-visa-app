## 2026-09-09 - [DOM XSS] Stored XSS via JSON Backups
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability was found when restoring user session state from a `.json` backup. The `app.js` file rendered task properties like `task.title`, `task.hint`, `task.guidance`, and `attachedFileInfo.size` directly into the DOM using `innerHTML` without proper HTML escaping. Malicious actors could construct a custom JSON backup with `<script>` tags or `javascript:` links in `task.sourceUrl` and socially engineer a victim into restoring it.
**Learning:** Even local-first applications are vulnerable to Stored XSS if they restore data from an external file (like an exported JSON backup) and render it directly to the DOM. Client-side state loading requires the same level of input sanitization as fetching data from a remote server.
**Prevention:** Always use `escapeHtml()` when interpolating any string from a state object into `innerHTML`. Implement a `sanitizeUrl()` function to filter out `javascript:` and `data:` schemes in attributes like `href`.
