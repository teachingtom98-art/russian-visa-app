## 2024-10-10 - DOM XSS via Task Details and Untrusted JSON Imports
**Vulnerability:** The `app.js` file dynamically generated task details (title, hint, guidance, source, and verified date) using `innerHTML` without fully sanitizing the inputs via `escapeHtml()`. Additionally, `sourceUrl` values were inserted directly into `href` attributes without validating the URL scheme to prevent `javascript:` execution. Since the application supports restoring state from a JSON backup file (`handleFileRestore`), an attacker could craft a malicious JSON file and trigger a DOM-based Cross-Site Scripting (XSS) attack when the victim imports the file.
**Learning:** Even entirely client-side, local-first applications are susceptible to XSS if they support importing untrusted structured data (like JSON backups). All properties loaded from local storage or file uploads and injected into the DOM via `innerHTML` must be treated as untrusted input.
**Prevention:** Always wrap variables injected into `innerHTML` strings with a robust `escapeHtml()` function. For `href` attributes, always validate that the URL strictly uses a safe protocol (e.g., `http://` or `https://`) using a helper function like `sanitizeUrl()`.
