## 2024-09-12 - Prevent XSS When Loading Untrusted Local State
**Vulnerability:** XSS vulnerability in `renderTaskList` via un-sanitized task attributes (`title`, `hint`, `guidance`, etc.) that were injected into `innerHTML`. Furthermore, malicious links could be injected in `sourceUrl` via `javascript:` scheme.
**Learning:** Local-first applications that load state from imported JSON files (local storage or file upload) must treat imported local state as untrusted data just like they would an external API payload. If not sanitized prior to DOM insertion, this can lead to cross-site scripting (XSS). Additionally, HTML entities encoding doesn't prevent XSS in URL contexts.
**Prevention:** Always use a sanitization helper (e.g., `escapeHtml`) when converting arbitrary state properties into HTML content before manipulating `innerHTML`. For URL attributes, ensure the URL uses a safe protocol (`http://` or `https://`) and explicitly discard unsafe URLs to prevent `javascript:` execution.
