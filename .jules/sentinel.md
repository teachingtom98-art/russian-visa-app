## 2024-05-24 - [CRITICAL] Fix DOM XSS via Unsanitized JSON Import
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) due to untrusted JSON data being imported and injected directly into the DOM using `li.innerHTML` in the `renderTaskList` function. Specific fields like `task.title`, `task.hint`, `task.source`, `task.sourceUrl`, and `task.guidance` were not sanitized. Further, `task.sourceUrl` was prone to javascript: scheme injection. Also, `escapeHtml` was not equipped to handle non-string inputs safely without throwing errors.
**Learning:** Even in local-first apps without backends, importing external JSON files creates an attack surface. Data needs to be treated as untrusted and sanitized before DOM insertion, regardless of the source. Using `String(str ?? '')` provides a safe way to handle nullish or non-string inputs before replacing HTML entities.
**Prevention:** Always apply HTML entity encoding to data injected into HTML elements via `.innerHTML` and validate URLs to ensure safe schemes (`http://`, `https://`) prior to injection.
