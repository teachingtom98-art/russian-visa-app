## 2024-10-07 - Cross-Site Scripting (XSS) via Untrusted JSON State Import
**Vulnerability:** The application allows users to import local JSON state backups containing tasks. Several string fields from these tasks (`title`, `hint`, `source`, `sourceUrl`, `verifiedDate`, `guidance`, `standardName`, file size, extension) were interpolated directly into `innerHTML` strings without HTML encoding or URL sanitization, resulting in a Stored XSS vulnerability triggered on import.
**Learning:** Even client-side only (local-first) architectures without a backend are susceptible to XSS if untrusted state files (like imported JSON backups) are rendered directly into the DOM. Trusting local imports is a critical mistake.
**Prevention:** Always sanitize all dynamically rendered data from JSON using HTML escaping (`escapeHtml`) before interpolating into HTML templates, and strictly validate/sanitize URL attributes to enforce safe protocols (`http:`, `https:`) using the `URL` constructor.
