## 2024-10-09 - XSS Vulnerability in Link Hrefs via Missing URL Scheme Validation
**Vulnerability:** Found an XSS vulnerability in `app.js` where untrusted URLs (`task.sourceUrl`) were rendered directly into the `href` attribute of an `<a>` tag via `innerHTML`. This could have allowed JavaScript execution if a malicious URL (e.g. `javascript:...`) was provided. Also, `task.title`, `task.hint`, etc., were not escaped before insertion via `innerHTML`.
**Learning:** `innerHTML` allows script execution if `href` attributes contain `javascript:` scheme. Validating the URL protocol (enforcing `http` and `https`) and properly escaping properties from JSON state before template literal assignment is crucial to preventing XSS, particularly in zero-dependency vanilla JS apps building templates manually.
**Prevention:** Implement and use a `sanitizeUrl` function to parse and enforce safe protocols, alongside `escapeHtml`, on any external or variable data added directly into DOM strings.
