## 2024-09-11 - DOM XSS in task list rendering via imported JSON state
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability was found in the `renderTaskList` function. Task variables such as `task.title`, `task.hint`, `task.guidance`, `task.source`, `task.verifiedDate`, `task.sourceUrl`, and `task.standardName` were directly interpolated into `innerHTML` string templates without sanitization. Since these values can originate from untrusted JSON backup files uploaded by the user, an attacker could craft a malicious JSON file to execute arbitrary JavaScript in the victim's browser if the victim restores from the malicious file.
**Learning:** This occurred because the application assumed the data source (local storage or JSON import) was safe and did not sanitize the data before dynamically rendering the HTML.
**Prevention:** Always sanitize untrusted input, even if it comes from seemingly safe sources like local storage or imported application state, before rendering it into the DOM. Utilize functions like `escapeHtml` to encode special characters and prevent execution of injected scripts.
