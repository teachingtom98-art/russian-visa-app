## 2026-10-11 - [HIGH] Fix XSS vulnerability in task rendering
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) due to unescaped user inputs injected directly into the DOM via `.innerHTML` in the `app.js` file (specifically in the `renderTaskList` function). Data attributes like `task.title`, `task.hint`, `task.guidance`, and `task.source` were not sanitized. Additionally, `task.sourceUrl` was not validated to ensure a safe protocol (e.g. `javascript:` URIs were possible).
**Learning:** Even client-side only applications that use `localStorage` and `IndexedDB` need robust data sanitization when data is imported, restored, or rendered because local data sources can be manipulated.
**Prevention:** Always use an escaping function (like `escapeHtml`) when injecting dynamic text into the DOM via `innerHTML` or template literals. Ensure that URLs injected into `href` attributes are sanitized to only allow safe protocols like `http:` or `https:`.
