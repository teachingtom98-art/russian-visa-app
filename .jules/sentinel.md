## 2024-10-31 - Cross-Site Scripting (XSS) via Unvalidated JSON Import
**Vulnerability:** The application allows users to restore state from a JSON backup. The imported JSON is not validated or sanitized before rendering its contents in `renderTaskList`. Fields like `task.title`, `task.hint`, `task.source`, and `task.guidance` were directly inserted into the DOM via `innerHTML`, allowing arbitrary HTML injection. Furthermore, `task.sourceUrl` was injected into the `href` attribute, permitting `javascript:` URI execution.
**Learning:** Even local-first applications are vulnerable to XSS if untrusted data (like a user-provided JSON file) is rendered into the DOM without sanitization. The application assumed the backup JSON was structurally sound and safe.
**Prevention:** All data coming from external files, including local JSON imports, must be treated as untrusted. Use a robust HTML escaping function before inserting strings into the DOM via `innerHTML`, or use `textContent`/`innerText`. Validate and sanitize all URLs injected into `href` attributes to allow only safe protocols (`http(s)`). Ensure escaping functions can handle non-string inputs (e.g., numbers, booleans) by safely casting to strings first.
