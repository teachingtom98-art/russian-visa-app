## 2026-09-30 - Prevent XSS in Local-First Application State Restoration
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) when importing a local JSON backup state. User-controlled properties (like `task.title`, `task.hint`, `task.sourceUrl`, etc.) from the imported JSON file were directly injected into the DOM via `innerHTML` without prior sanitization. Additionally, the `sourceUrl` lacked validation against malicious schemas (like `javascript:`).
**Learning:** In a local-first application where state is stored via IndexedDB and exported/imported via JSON, imported JSON state must be treated as fully untrusted user input. Using `innerHTML` requires rigorous escaping of all dynamic values.
**Prevention:** All user-controlled fields mapped to the DOM must be sanitized using `escapeHtml()`. Hyperlink values (`href`) require additional validation using a custom `sanitizeUrl()` function to explicitly enforce `http:` or `https:` protocols and neutralize malicious schemas like `javascript:`.
