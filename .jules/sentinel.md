## 2026-09-13 - [CRITICAL] Fix Cross-Site Scripting (XSS) in task list rendering
**Vulnerability:** A Cross-Site Scripting (XSS) vulnerability was found in `app.js` during the generation of task list HTML. The dynamic task variables from imported JSON states (such as `task.title`, `task.hint`, `task.guidance`, `task.source`, `task.verifiedDate`, `task.standardName`, and `attachedFileInfo.size`) were interpolated directly into the `innerHTML` of list items without any sanitization. This allowed execution of arbitrary JavaScript if a malicious JSON state backup was restored. Furthermore, `task.sourceUrl` was directly interpolated into an `href` attribute, allowing for `javascript:` protocol payloads.
**Learning:** Even in local-first apps relying on JSON imports, untrusted structured data must be heavily scrutinized before being injected into the DOM. This issue highlights the danger of relying on `innerHTML` when reconstructing UI from potentially manipulated serialized state.
**Prevention:** Always use safe methods like `textContent` where possible. If `innerHTML` must be used for layout flexibility, unconditionally sanitize all interpolated dynamic string variables using a robust escaping function (like `escapeHtml()`). For URL insertions into `href` or `src` attributes, always validate and enforce safe schemes (`http:`/`https:`) to neutralize protocol-based execution vectors.
