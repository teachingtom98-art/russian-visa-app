## 2024-05-15 - Unsanitized User Input in DOM Injection (XSS Vulnerability)
**Vulnerability:** Found multiple instances where properties from JSON state (like `task.title`, `task.hint`, `task.guidance`, `task.source`, `task.sourceUrl`, and `task.verifiedDate`) were injected directly into the DOM via `innerHTML` without HTML entity encoding, leaving the application open to Stored/DOM-based Cross-Site Scripting (XSS) when a malicious JSON file is imported.
**Learning:** Directly concatenating object properties into `innerHTML` strings without first passing them through a sanitization function (e.g., `escapeHtml()`) creates severe XSS vulnerabilities, especially in an application where state can be imported from untrusted JSON files.
**Prevention:** Always wrap any untrusted or dynamically imported string data in a sanitization function like `escapeHtml()` before interpolating it into HTML template strings that will be assigned to `innerHTML`. Further, ensure URL attributes are sanitized to require safe protocols like `http:` or `https:`.
