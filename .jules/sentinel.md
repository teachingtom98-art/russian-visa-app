## 2026-09-15 - XSS Vulnerability in JSON Backup Import
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) when importing state from a JSON backup. Multiple properties from the backup JSON (like `task.title`, `task.hint`, `task.guidance`, `task.source`, and `task.verifiedDate`) were concatenated directly into an `innerHTML` template string without any HTML escaping. The `task.sourceUrl` field was also used in an `href` attribute without URL scheme validation.
**Learning:** Local-first applications that load state (even JSON backups saved locally) into the DOM are highly susceptible to XSS if the backup file is maliciously modified or crafted by an attacker and then imported by the victim. In a sensitive context (like a visa planner tracking passports), this could allow a malicious actor to steal IndexedDB blobs containing passport scans.
**Prevention:** All untrusted user-controllable data (including properties from imported JSON files) must be escaped (e.g., using `escapeHtml`) before being inserted into the DOM via `innerHTML` or similar unsafe APIs. URL inputs must be validated to ensure they use safe schemes (e.g., `http://` or `https://`).
