## 2024-05-24 - [DOM-Based XSS in renderTaskList]
**Vulnerability:** User-controlled properties within tasks (like `task.title`, `task.hint`, `task.source`, `task.verifiedDate`, `task.guidance`, and `task.sourceUrl`) were being injected directly into the DOM using `innerHTML` in the `renderTaskList` function. Since task data can be imported from JSON state files (`handleFileRestore`), an attacker could craft a malicious JSON backup file and trick a user into restoring it, executing arbitrary JavaScript in the context of the user's browser.
**Learning:** Even when the app relies on "local-first" storage, importing arbitrary JSON state from disk is equivalent to taking untrusted user input. Any data dynamically loaded from outside the immediate source code should be treated as untrusted and properly sanitized before being inserted into the DOM.
**Prevention:** Always use `escapeHtml` to sanitize untrusted properties before string interpolation into `innerHTML`, and use a `sanitizeUrl` function to ensure that URLs do not use `javascript:` protocols.
