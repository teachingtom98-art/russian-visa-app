## 2024-05-18 - [Fix XSS vulnerability in JSON imports]
**Vulnerability:** The application imports JSON backup state to restore a user session. Untrusted input from JSON files like task titles, task hints, source URLs, and task guidance strings were being inserted directly into the DOM (innerHtml) without sanitization or HTML escaping, introducing Cross-Site Scripting (XSS) risks.
**Learning:** `javascript:` URIs in `href` links can be injected via `task.sourceUrl`, and arbitrary HTML nodes and scripts can be injected in other fields. This introduces a vulnerability as malicious users can craft harmful JSON files, social engineer other users to import them, and run malicious scripts within their browser session.
**Prevention:** Always use `escapeHtml` to escape untrusted strings before appending them to `innerHTML`. For URLs used in `href` attributes, always validate and limit the scheme (e.g. enforcing `http:` or `https:`) and filter out `javascript:` URIs using a secure function like `sanitizeUrl`.
