## 2024-10-08 - [HIGH] Fix Cross-Site Scripting (XSS) in JSON state imports
**Vulnerability:** XSS vulnerability via maliciously crafted JSON state imports in `app.js`. Task attributes like `title`, `hint`, `source`, `verifiedDate`, and `guidance` were unescaped when interpolated into HTML string templates in `renderTaskList()`. Furthermore, `task.sourceUrl` was directly injected into an `<a href>` tag without validation, allowing for `javascript:` URI attacks. The `escapeHtml` function also assumed string input and could be bypassed with maliciously crafted non-string objects.
**Learning:** Even entirely local, single-page applications without a backend must sanitize user-provided data, especially when state can be exported and imported (JSON backups). The data might come from an untrusted source attempting to exploit a user loading their state.
**Prevention:** Always use `escapeHtml` for any text interpolated into DOM elements (especially innerHTML). Sanitize URLs to ensure safe protocols (`http://`, `https://`) using a dedicated `sanitizeUrl` function to prevent `javascript:` execution. Ensure escaping functions cast inputs to Strings to prevent object bypass attacks.
