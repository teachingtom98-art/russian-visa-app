## 2024-05-18 - XSS via Local JSON Import
**Vulnerability:** Cross-Site Scripting (XSS) vulnerability found during JSON import parsing. Values like task title, hint, source, and others were injected directly into the DOM without sanitization, assuming that local imported JSON state is trusted.
**Learning:** Even when the app architecture is local-first and there's no backend server involved, data loaded from a local file (e.g., a `.json` backup file) must still be treated as untrusted user input, as it could have been manipulated by the user or tampered with by a malicious third party.
**Prevention:** Always apply HTML sanitization (like `escapeHtml`) to any string originating from an imported JSON file before injecting it into the DOM, and validate URI schemes (e.g., using a `sanitizeUrl` function) to prevent `javascript:` execution. Ensure your sanitization functions correctly handle nullish or non-string values typically found in JSON (like booleans or numbers) by explicitly casting them to strings.
