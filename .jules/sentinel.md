## 2024-05-18 - Cross-Site Scripting (XSS) in Task Rendering
**Vulnerability:** In `app.js`, multiple task properties (`title`, `hint`, `source`, `verifiedDate`, `sourceUrl`, and `guidance`) from `currentSession` were directly injected into the DOM via `innerHTML` without sanitization. An attacker could craft a malicious JSON backup file and execute arbitrary JavaScript if a victim restored the backup.
**Learning:** Even in purely client-side local-first applications without a backend, importing and restoring state (like JSON backups) represents an untrusted boundary. Any properties injected into the DOM must be properly sanitized, regardless of the presumed source.
**Prevention:** Always use a utility function like `escapeHtml` to sanitize dynamic text properties before inserting them via `innerHTML` or string interpolation, and validate all URL schemes using a method like `sanitizeUrl` to enforce `http://` or `https://` schemas instead of `javascript:` or `data:`.
