## 2024-05-18 - XSS via Insecure JSON State Import Deserialization
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) because unescaped fields from the imported JSON state file (`task.title`, `task.hint`, `task.sourceUrl`, etc.) were directly injected into the DOM via `li.innerHTML` inside the `renderTaskList` function.
**Learning:** Even though the application uses local storage and local files, it accepts untrusted data through the JSON import feature. The local-first nature of the application doesn't protect against malicious users crafting a crafted JSON backup file that, when imported, executes arbitrary JavaScript on the application context.
**Prevention:** Always escape HTML entities (`escapeHtml`) when rendering text content into HTML templates and always validate and sanitize URLs (e.g. enforcing http/https, denying `javascript:`) before inserting them into `href` attributes, regardless of where the data seems to originate from.
