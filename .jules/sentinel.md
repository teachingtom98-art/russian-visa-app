## 2024-05-24 - XSS via Untrusted JSON State Import
**Vulnerability:** The application was vulnerable to Cross-Site Scripting (XSS) due to insufficient sanitization of imported JSON state data. Specifically, several properties in the `currentSession.tasks` array (like `task.title`, `task.hint`, `task.guidance`, `task.source`, `task.verifiedDate`, `task.standardName`, and `task.attachedMeta.size`) were injected directly into the DOM using `li.innerHTML` without being escaped. Also, `task.sourceUrl` was used directly in `href` attributes, allowing `javascript:` URIs.
**Learning:** Even though the application uses `escapeHtml` for some fields (like `task.attachedMeta.name`), all untrusted data, especially from file imports, must be sanitized. It is also important to handle non-string inputs in `escapeHtml` (e.g. using `String()`) to prevent type confusion bypasses.
**Prevention:** Thoroughly wrap *every* variable injected into HTML string literals with an improved `escapeHtml` that casts inputs to strings. For URLs injected into `href` attributes, use a `sanitizeUrl` function to strictly enforce `http://` or `https://` schemes.
