## 2024-10-04 - XSS via Untrusted JSON State Import
**Vulnerability:** A critical Cross-Site Scripting (XSS) vulnerability existed where untrusted data from imported JSON backups (`task.title`, `task.hint`, `task.sourceUrl`, etc.) was being directly inserted into the DOM via `innerHTML` without sanitization. Because the app restores session state from local storage or uploaded files, this could be exploited by importing a maliciously crafted JSON file.
**Learning:** Even client-side only (local-first) applications without a backend can suffer from XSS if they process and render unsanitized local files or user-supplied JSON backups using `innerHTML`. This is especially critical when the state contains attributes that get evaluated, like `href`.
**Prevention:** Always sanitize data before DOM insertion. Used an `escapeHtml()` function for all text content and created a `sanitizeUrl()` function to ensure URLs use `http:` or `https:` protocols, preventing `javascript:` URI attacks.
