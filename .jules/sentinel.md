## 2023-11-22 - [CRITICAL] Fix Stored XSS in JSON state imports
**Vulnerability:** The application was vulnerable to Stored XSS due to directly injecting unsanitized data from uploaded JSON state files (e.g., `task.guidance`, `task.title`, `task.hint`, `task.source`, `task.verifiedDate`) into the DOM via `innerHTML` in the `renderTaskList` function. Furthermore, `task.sourceUrl` was directly injected into an `href` attribute, leading to `javascript:` execution when clicked.
**Learning:** Even local-first applications are vulnerable to Stored XSS if they allow importing external state files (like backups) without validating or sanitizing the contents before injecting them into the DOM.
**Prevention:** Always apply HTML encoding (`escapeHtml`) to any dynamic user or imported data before interpolating it into HTML markup. For URLs injected into `href` or `src` attributes, ensure they use safe protocols (e.g. `http://` or `https://`) using a validation function (e.g. `sanitizeUrl`).
