## 2023-10-27 - DOM XSS via Malicious JSON State Backup Import
**Vulnerability:** The application allows importing state via JSON files, which is then parsed and injected directly into the DOM using template literals (in `renderTaskList` and `generatePrintableSummaryHtml`). Fields like `task.title`, `task.hint`, `task.guidance`, and `task.sourceUrl` were inserted into the page's HTML structure without sanitization, leading to critical DOM-based Cross-Site Scripting (XSS).
**Learning:** Local-first apps that load or import state from local JSON blobs still face injection risks. Trusting the imported file format just because it comes from the user's filesystem is unsafe; maliciously modified backup files can inject scripts leading to execution in the user's browser context.
**Prevention:** Always sanitize ALL data extracted from any importable state format before injecting it into the DOM, even if the data purportedly originated from the app itself. Use `escapeHtml()` for text nodes/attributes and enforce safe URL schemas (e.g. strict `http:`/`https:`) using a function like `sanitizeUrl()` to prevent `javascript:` payload execution.
